# SV2 账号槽位与并发启动

Windows 使用固定的账号数据目录。普通启动和同账号的所有 Sandboxie 实例都读写这份目录：

```text
Synthesizer V Studio 2.toolbox-slots/
  slots/<账号 ID>/           账号、授权缓存、声库、设置、脚本
  instances/<账号>/<实例>/   独立的 Sandboxie 注册表和 IPC 环境
```

官方 AppData 数据路径是指向主账号槽的受管目录链接。首次并发启动建立账号隔离环境，将环境内的官方数据路径链接到所选账号槽；再次启动复用已验证的同账号环境。改变主账号不会改变已运行实例所使用的账号目录。

声库按账号保存，同一声库由不同账号下载的文件可能含不同水印。工具箱不跨账号合并或同步 `databases`，也不共享账号会话、Cookie 或 WebView2 数据。

跨账号默认同步脚本、用户词典、预设和明确允许的设置文件，包括 `settings/settings.xml`。新建账号以及启动空闲账号时，从当前主账号同步这些内容；目标账号已有实例运行时，不覆盖其文件。也可以使用账号页的选择性同步预览检查变更。

Windows 并发启动需要可用的 Sandboxie Plus / Classic。账号已有运行进程时，可以在同一环境继续启动多个进程；账号数据不会按进程复制。工具箱不改变 Dreamtonics 的账号授权或官方并发限制。

账号页的实例列表显示窗口标题、PID、运行模式和账号，并在页面可见时自动更新。工具箱依据受管 Sandboxie 实例中的 PID 关联账号；明确识别为普通 SV2 的进程使用当前主账号。Flat、SV1、无法确认隔离状态或未知 Sandboxie 实例显示为未关联。窗口标题反映当前工程名称；标题没有提供完整路径时，列表不会推测工程路径。

当前主账号可直接再次普通启动，不受已有进程数量限制。切换主账号仅在普通 SV2 或插件未占用官方数据路径时执行。已识别的受管并发实例不会阻止主账号切换。进程查询失败时保留错误，不把未知状态当作账号空闲。

开启账号登录指示器后，可以主动刷新账号授权。空闲账号可以执行官方会话预检；运行中的账号仅使用未过期的会话查询授权，查询后再次检查会话文件是否变化。运行中探测不刷新、写回或登记登录会话。过期会话、账号冲突、网络失败和持久化失败分别显示实际状态。

同账号所有模式共用一份登录态保护记录与恢复快照。任何实例还在运行时都不会恢复或覆盖账号会话。

旧数据收敛时只信任所属账号标记。此前使用的 sandbox 数据成为账号唯一活跃数据；存在不同的普通槽位数据时保留在受管归档目录，供核对。旧全局声库目录保留原文件，但解除账号对它的共享链接；需要在各账号的 SV2 中确认并下载对应声库。无法确认归属的目录不会被覆盖。

macOS 继续使用顺序槽位：SV2 与插件退出后，整体切换账号数据目录；不提供 Sandboxie 并发。声库同样按账号保留。
