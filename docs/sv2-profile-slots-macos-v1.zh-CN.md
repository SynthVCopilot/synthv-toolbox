# macOS SV2 槽位 v1

macOS 槽位以顺序切换为边界：工具箱只在 SV2 与相关插件完全退出后，切换本地账号、设置、缓存和脚本所在的数据根：

```text
~/Library/Application Support/Dreamtonics/Synthesizer V Studio 2
```

声库数据库按账号独立保留，不跨账号复制或共享；默认只同步脚本、词典、预设和明确允许的设置。工具箱不解析、修改或复制账号数据。切换由清单、槽位标记和持久化日志保护；中断时只进行确定性恢复，不删除未知目录。

v1 不提供同一桌面的多实例运行、强制结束进程、账号登录预检或授权读取。需要并行使用时，请使用独立 macOS 用户会话或虚拟机，并遵守 Dreamtonics 的账号与授权规则。
