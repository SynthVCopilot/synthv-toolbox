# SynthV Toolbox 0.2.0 发布说明

0.2.0 汇总了 0.1.6 之后逐步完成的桌面工作流改进。

## 连接、账户与工作区

- 集中管理 Synthesizer V 账户槽位、已安装声库和多个运行实例。
- 在一个连接页中配置 Bridge、外部工具和本地 HTTP MCP，并管理多个 AI 服务的凭据与对话。
- 支持 Bridge 安装发现、连接诊断、登录自启动和中英文界面。
- 自动发现工程并保存可恢复的本地历史副本。

## 音频与工程工作流

- 导入平台音频，管理所需组件，并进行人声与伴奏分离。
- 准备音频、生成 MIDI、保留歌词和标记信息，再导入 Synthesizer V。
- 提供一键 Cover、Edit / Solo 调音工作模式，以及按声库保存的调音档案。

## 更新与创作

- 可从关于页检查稳定渠道的应用更新。
- 下载、查看并管理可用更新，保留清晰的安装提示。

## Bridge 与写词

- 在应用内查看 Bridge 会话状态，并启动、停止或切换受控连接。
- 从 Synthesizer V 读取当前选区，为音符生成歌词分配预览，并在确认后写入。
- 预览会在编辑、切换选区或会话变化后失效，避免迟到结果覆盖当前内容。
- 保存候选和旧稿，便于恢复与导出。
- 使用 [Bridge 连接与写词指南](https://github.com/SynthVCopilot/synthv-toolbox/blob/main/docs/bridge-and-lyrics.zh-CN.md) 完成连接和写词流程。
