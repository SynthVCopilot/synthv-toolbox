# Session 内部读写

## 目标

在插件宿主能力中增加受 `host.internal` 管控的 session 完整读写接口。读取返回未经裁剪的明文和当前密文哈希；写入接受完整明文，以旧密文哈希作为并发保护，并在替换前生成可验证备份。

## 实施步骤

1. 梳理 session kit、插件权限与宿主能力分发边界。
2. 从 session kit 提取可复用的完整读取和受保护写入 API。
3. 注册 `synthv.session` 的 `read`、`write` 操作并强制 `host.internal` 权限。
4. 修复账号设置中的离线区域布局，并增加完整授权明细展开区。
5. 将离线启用和停用流程改为能显示当前步骤、完成状态与失败原因的弹窗。
6. 使用临时合成 session 验证完整内容保留、备份、哈希保护和恢复路径。
7. 运行 Rust、Node、前端构建检查，提交并交付开发构建。

## 验收标准

- 插件能读取 session 的完整解密文本，不丢失未知字段。
- 插件能提交完整文本并写回相同路径。
- 每次写入必须提供当前密文哈希，目标变化时拒绝覆盖。
- 写入前生成不可覆盖的已验证备份，写入失败时恢复原始内容。
- SV2 正在运行时拒绝写入；当前 Toolbox 进程不阻止内部调用。
- 未获得内部函数授权的插件无法调用该能力。
- 用户可以展开查看自己的 access、refresh、到期时间、设备/用户字段和完整产品字段。
- 离线切换期间显示逐步进度，失败时保留出错步骤和错误消息。
- 操作说明保持正常横向排版，不被压缩成单字列。
- 所有测试只使用临时目录和合成数据。
