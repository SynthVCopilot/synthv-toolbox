# MCP 服务器特权开关

## 目标

让 Toolbox 本地 MCP Server 可分别启用内部函数与高级功能。两个开关默认关闭、独立持久化；未开启时不发布对应工具，直接调用也必须由 Rust 宿主拒绝。

## 实施步骤

1. 复用现有宿主能力分发器，为 MCP 增加内部函数与高级功能两个显式入口。
2. 扩展设置、HTTP 服务上下文、状态与配置命令，使两个开关独立持久化并即时生效。
3. 在连接设置页增加两个开关及风险说明。
4. 补充 Rust 与前端合同测试，验证默认关闭、工具列表过滤及调用时二次鉴权。
5. 完成格式化、构建与测试后交付主分支。

## 边界

- 内部函数入口只接受现有 `host.internal` 能力集合。
- 高级功能入口只接受现有 `host.advanced` 能力集合，包括不受插件数据目录约束的文件访问与不限制目标地址的网络请求。
- MCP 授权与插件的全局、单插件授权相互独立。
