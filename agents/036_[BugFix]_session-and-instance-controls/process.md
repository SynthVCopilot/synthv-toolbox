# 实例控制

发现、聚焦和终止均以当前可执行文件路径的严格 Synthesizer V 身份为边界。控制调用同时校验 PID 和进程身份令牌，避免 PID 复用或同名安装工具被操作。

Windows 使用进程启动时间、文件版本、窗口枚举与目标进程终止 API；macOS 使用启动时间、应用 bundle 元数据、辅助功能聚焦和目标 PID 的 SIGTERM。两端都只会操作经过重新验证的单个实例。

复审后保留 SV1 的精确可执行文件识别。Windows 在保持目标进程句柄期间重新读取映像路径和启动时间后才聚焦或终止，避免 PID 复用窗口；macOS 枚举改为仅取 `ps` 的完整 `comm` 字段，避免把带空格的路径或参数误解析为可执行文件。
