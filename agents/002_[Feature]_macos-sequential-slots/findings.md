# 技术调研

- [数据根] -> SV2 用户数据位于 macOS Application Support，声库数据库由最新共享存储模型集中管理 -> 槽位切换保留账号、缓存和设置，声库通过受管符号链接共享。
- [并发边界] -> macOS 没有 Windows Sandboxie 的文件、注册表和 IPC 隔离机制 -> v1 只提供顺序切换，不提供强制结束或同桌面多实例。
- [占用检查] -> `ps` 可以识别 standalone，`lsof` 可以识别当前数据根的实际打开者 -> 切换在任一占用存在时停止。
- [验证] -> 单线程 Rust 全量测试通过；默认并行模式中已有音频测试与组件使用锁竞争 -> 槽位测试和全量串行验证均通过，未修改无关的上游音频实现。
