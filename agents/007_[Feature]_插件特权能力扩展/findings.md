# 技术调研

- 账号槽位服务已有事务性切换、恢复、强制终止占用进程、受管 session 和并发隔离操作；只有具备明确输入和既有保护措施的单操作适合导出。
- 云端账户真正撤销需要官方服务的已验证接口；当前可安全实现的是清除本机受管 session，不宣称会撤销远端会话或官方授权。
- 离线授权缓存保存在加密 session 的产品行中。可以在不暴露密钥且保留登录凭据的条件下，清除这些本地缓存行并保存受限权限备份。
- 内部接口覆盖账号操作、诊断、受管路径和运行时状态；每个操作均为固定名称，并在 Rust 中重验 `host.internal` 与必要参数。
- 目录能力只返回经受管根目录、槽位标识和重解析点校验后的路径；账号探针序列化会跳过内部 account key，不返回 AI 凭据或会话密钥。
