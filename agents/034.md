# 决策与理由

- 账号下载的声库含各自水印，禁止跨账号合并数据库；每个账号的 slot 和 sandbox 使用同一权威数据位置。
- 同账号在同一环境可以多进程；复用已验证 Sandboxie 环境，移除以进程存在或互斥量名称推导的启动限制。
- 保留已有用户数据；不做破坏性清理或终止用户的 SV2 进程。
- 用户要求多项任务分派子 agent；使用独立 worktree，本地合并，不包含已有其他任务分支。

## 并发存储实现决策

- 每个账号槽位的数据根是唯一权威源；Sandboxie 的账号隔离环境拥有独立的 overlay 根，并以 `OpenFilePath` 直接映射该账号根。
- 不再创建跨账号共享的 `databases` junction。保留既有磁盘内容，迁移仅解除工具箱创建且可验证的链接。
- 会话保护按账号权威根运行，避免同账号多个实例对同一 session 创建相互矛盾的恢复副本。

- 用户明确澄清 SV2 支持同账号同环境多进程。普通启动仅在目标账号不同、确实需要改动官方数据路径时检查占用；已有普通进程只使会话探测采用只读模式。
